##### **Let us understand some basic terms of the JavaScript:**

* **V8 Engine:**

  * V8 engine is an open source, JavaScript engine that executes JS code at a high speed. V8 translates JavaScript code directly into machine code that a computer's processor can understand and execute. Unlike traditional interpreters which read code line by line, V8 compiles JS code into a native machine code using a technique like JIT (Just in time) compilation, making execution much faster.
* **Var:**

  * var declares variables with function or global scope and allows both re-declaration and reassignment.This means var variable can be access anywhere in the function where it's declared, even outside the code blocks, like if statements and loops.
* **Let:**

  * let declares variables with block scope (limited to {} where they're defined), allows reassignment but prevents re-declaration in the same scope.This makes let safer than var by preventing accidental variable overwrites.
* **Const:**

  * const declares block-scoped variables that cannot be reassigned after their initial value is set. However, if a const holds an object or array, you can still modify the contents (like adding array elements or changing object properties) - you just can't reassign the variable to a completely different value.

    

#### Key differences comparison:

| Feature        | var             | let   | const |
| -------------- | --------------- | ----- | ----- |
| Scope          | Function/Global | Block | Block |
| Reassignment   | Yes             | Yes   | No    |
| Re-declaration | Yes             | No    | No    |



* **Keywords:**
  * Keywords are reserved words built into JavaScript that have special meanings and define actions to be performed.
  * You cannot use keywords as variable names or function names because they are part of the language's core syntax.
* **Identifiers:**
  * Identifiers are names you create for variables, functions, objects or classes.
  * Rules for identifiers:
    * Can contain letters, digits, underscore (_) and dollar sign ($).
    * Must start with a letter, underscore or dollar sign (not a digit).
    * Cannot be Keywords.
    * Are case sensitive (`userName` and `username` are different.)
* Literals:
  * Literals are fixed values written directly in code that represent data. They are actual values to assign, not variables that hold values.
